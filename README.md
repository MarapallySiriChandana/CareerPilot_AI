# CareerPilot AI

CareerPilot AI is a responsive AI-powered career guidance landing page designed to help students and freshers improve their career preparation. The website provides features such as resume analysis, interview preparation guidance, skill gap detection, pricing plans, and a contact form.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Smooth scrolling navigation
- AI Career Dashboard mockup
- Resume Analysis section
- Interview Preparation section
- Skill Gap Detection section
- Pricing plans (Starter, Pro, Premium)
- Contact form with JavaScript validation
- Modern UI with hover effects
- Bootstrap integration

## Technologies Used

- HTML5
- CSS3
- JavaScript 
- Bootstrap 5
